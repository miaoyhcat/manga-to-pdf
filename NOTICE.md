# NOTICE

## Personal use only / 自用非商用

This project is a personal hobby tool. It is **not a service**, it is not commercial, and the
author does not operate or endorse any public instance.

- Use it for material you already have legitimate access to.
- Do not sell it, do not run it as a paid service, do not wrap it in ads.
- Do not use it to build a redistributable library.

## Support the official releases / 请支持正版

Buy the books. Subscribe to the sites you read on. Use the official app when one exists.

This tool does **not** bypass paywalls, DRM, subscriptions or region locks. If a work is paid,
exclusive or restricted, use the official platform — that is the only place those features
work properly.

Downloading from a site does not transfer any rights: everything you fetch remains the property
of its authors and publishers.

## It is incomplete / 本项目并不完善

Treat it as a rough hobby script with a web UI, not a product:

- single worker queue, no priorities, no per-user account system
- retries and rate limits are best-effort; upstream changes break things
- only three UI languages, and the wording is not polished
- Windows and Linux paths differ, notifications are basic, logs are plain files
- no tests; verification is manual

Expect breakage. Issues and pull requests are welcome, but there is no support commitment.

## Some features only exist upstream / 部分功能仅官方平台提供

Things that are **not** here and will not be added: reading-progress sync across devices,
comment threads, chapter release notifications, account-bound favourites and history, offline
libraries, creator subscriptions, purchase and tipping flows.

Those belong to the official platforms. If you need them, use the official app.

## Self-host it, don't crowd someone else's box / 请自己部署

The reason this is published is so that **you can run your own copy**. Please do not point
friends at somebody else's instance, and do not treat an existing deployment as a public
service: it has no authentication, and one heavy user can get the host's IP rate-limited.
